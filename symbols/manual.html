This manual says how to place the symbols of the six hand-maintained libraries in this folder. A symbol's Description says what the symbol is. This manual says how to use it. Symbols are grouped by pattern: Role, then Appliance or Kind, then the pin set. Every symbol appears once, as Library:Symbol with its Description as it stands in the file.

Terms

  • Signal indication. The meaning of an aspect, as the rulebook states it. Examples: Stop, Restricting, Clear. This manual says "indication".
  • Aspect. The appearance of a signal: the colours, positions and flashing of all its heads together. A head alone does not show an aspect.
  • Head. One unit of lamps on a mast. It shows one part of an aspect. Mast. The structure that carries one or more heads.
  • Control point. A named place where a dispatcher or operator controls train movements by controlled absolute signals.
  • Track circuit. The section of track that one track relay detects, between insulated joints.
  • Code line. The communication path between the CTC machine and the field units. It carries controls to the field and office indications to the office.
  • Control. A function sent from the office to the field (783NWS). Office indication. A function sent from the field to the office (783NWK).

Fields and pins common to every symbol

  • Role. The class of the symbol. The tools read Role, never the symbol name. A symbol with no Role is a drawing only.
  • Name. The identity of a named symbol. Its default is ${Value}. Set Value; Name follows. Value itself is never read.
  • Kind. The sub-class, where Role alone does not say what the symbol is. Fixed by the symbol, except on a mast.
  • Appliance. What an APPLIANCE, DEVICE or PANEL symbol is: switch, track_circuit, mast, head, lamp, contact, lever, train_order. Fixed.
  • Style. The variant inside an Appliance. Fixed by the symbol.
  • CP Name. The control point the symbol belongs to. Empty means the sheet's interlocking.
  • Pin.<pin>. The kind of value a function pin carries: binary, level, position, color, indication, message. Fixed.
  • Settings. Every other field in lower_snake_case, for example settle_ms. Set them per placement; empty means the default.
  • Invert. Names this symbol's pins whose sense is inverted. Fixed.
  • A pin named ~{X} is asserted low. A pin's electrical type is its direction: input, output or bidirectional.
  • Membership pins join a net and carry no value: Column, IOBus, Processor, Transport, Codeline, MC, CHAIN.
  • A device pin that meets a driver pin is an input of the device. Connections are read from the netlist, never from coordinates.

Trackplan symbols

One interlocking's trackplan is one sheet. Role decides what is on it: TRACK, POLICY, APPLIANCE and the House.

Office symbols

The office sheet holds the CTC machine, its columns and plates, the transports and the encodings that ride them.

Field symbols

A field sheet holds the devices of one interlocking: the hardware that acts on and senses its appliances, and the drivers that own the pins. A device is matched to its trackplan appliance by Name. Set Value to the appliance's name. Each unit of a device has one capability: one pin kind and one direction. Units are not interchangeable.

Hardware I/O symbols

A driver owns pins. It sits on an IOBus and hands its pins to devices, encoders and plates. IC names the chip or the encoding. Pin.<pin> states each pin's kind. Wire IOBus to the Processor's IOBus, or to a CMRInet node's IOBus. The devices on a driver's pins run on that processor.

A joint bounds a track circuit; an end closes the drawn track; an anchor states a fact about the point it sits on. Pins A and B are the two sides of a joint; wire track to each. EoT is the one track pin of an end. To is the track pin of an anchor.

  • IRJ and IRJ_Diag (Kind IRJ) differ in glyph only; IRJ_Diag is drawn on a diagonal.
  • IRJ-Signal has pin SIGNAL; IRJ-Signals has SIGNAL_A and SIGNAL_B. Wire a mast's SIGNAL pin to one. Set CP Name to the mast's control point.
  • IRJ-END_CTC has pins CTC (1) and DARK (2). CTC faces the controlled trackage, DARK the track beyond. The glyph draws a three-sided box around the end of the controlled track.
  • Bumper (Kind BUMPER) has no setting. Industry (Kind INDUSTRY): set Value to its name.
  • Milepost has no pin. Set Value to the milepost.
  • NextCP (Kind NEXT_CP): wire To to the track that leaves the interlocking. Set Value to the next interlocking's name; the Interlocking field follows. Not Modeled (Style off_layout) says the next interlocking is not drawn anywhere.

A policy symbol states the rule that governs a track. Kind is the rule number. Direction is fixed: LEFT, RIGHT or BOTH. Place one per governed track. Wire pin To (Rule 261: Track) to the governed track net.

  • The two plates (Kind RULE_290_G, RULE_290_R) have no Direction. Their pin To is wired to the same IRJ-Signal pin as the mast they modify.

A structure declares a named thing that owns or contains others. Kind says which. Set Value to its name.

  • Interlocking (Kind INTERLOCKING): one per trackplan sheet (Luchessa). Wire Codeline to the code line and Processor to the processor that runs the logic.
  • House (Kind CONTROL_POINT): one per control point. Set CP Name (CP Luchessa) and Milepost. Wire Codeline to the code line and MC to the MaintainerCall.
  • Station (Kind STATION): set Milepost. No pin. Railroad (Kind RAILROAD): one per project; set Era, Railroad, Region, Rulebook. No pin.
  • Processor (Kind PROCESSOR): one per processor; set Board. Pin Processor is the net its units attach to; pin IOBus is the bus its drivers sit on.

A switch appliance is a point in the track, named for the dispatcher. Place one per switch or derail. Style says what it is: powered, manual, manual_sensed, lock, dual, derail.

  • Set Value to the switch name (783). A lock shares its name with its switch. A dependent derail is named <switch>D (795D).
  • Pins C, N, R are track: C the point end, N the normal leg, R the reverse leg. A derail has C and R only; R is the through pin.
  • TC names the switch's OS track circuit; its default is <Value>T1. Set it when the circuit has another name. Indication is <TC>K, fixed.
  • IndicationCeiling is empty by default: the route derivation sets each route's ceiling from its context. Filled, it overrides that with two indication words, NORMAL/REVERSE: a route through this switch in that position never shows better than the word.
  • Switch_Powered, _Diag and _Small have the same fields; the glyphs differ. _NO_TC, Switch_Manual, Switch_Manual_Sensed and Derail have no OS circuit: TC and Indication are empty.
  • A derail has IndicationCeiling STOP/RESTRICTING: NORMAL is derailing. A manual switch has no library value; the route derivation's rule for hand-operated switches applies.

A track circuit marker names the circuit of the track net it sits on. Place one per circuit. Set Value to the circuit name (1NA). Indication is <Name>K, fixed.

  • Track Circuit, _RED and _Yellow have pin TC; wire it to the track net. They differ in drawn colour only.
  • IR Boundary (Style boundary) has pins A and B, one per side of the boundary. The pins imply no direction.
  • _Virtual (Style virtual) has no pin. Set Members to a comma-separated list of circuit names. Display shows them.

These masts carry their heads as trackplan symbols. Place one mast and one Signal Head per head pin. Mast: set Value to the mast name (784EAB). Kind is fixed per symbol: CONTROLLED, ABSOLUTE or PERMISSIVE. Wire SIGNAL to an IRJ-Signal or IRJ-Signals SIGNAL pin. Wire each head pin (H, H1, H2) to a Signal Head's pin M. Head: set Value to the head letter (A). Style is fixed: CL, CPL, LQ, UQ. The head device on the field sheet must have the same Style.

These masts carry no head symbols; the head glyphs are picture. The heads are field devices on a field mast device of the same Name. Place one per signal. Set Value to the mast name. Kind is fixed per symbol. Wire SIGNAL to an IRJ-Signal or IRJ-Signals. Leave Indications empty: the indications the mast must show are derived. Fill it only with an explicit comma-separated list of indication names; the list replaces the derived set.

  • Style is single, double, triple, dwarf, dwarf_double or stop_sign. Kind is CONTROLLED unless the name says ABSOLUTE or PERMISSIVE.
  • Stop is ABSOLUTE with Indications fixed to Stop.
  • Set Value to the signal name and Station to a station in the same interlocking: an operating requirement associates train orders with that station. The board has one or two faces, N/W and S/E, by direction of traffic. The faces, their heads and the fascia controls are field devices (Device-TrainOrder, one unit per face, pins STOP, SLOW, CALLON in and IND out; nothing asserted shows CLEAR, the most restrictive asserted input wins). Pin H is retired with the trackplan heads.

These appliances have one pin, MC. They are the office's view of a non-vital input or output at a control point.

  • AUXILIARY (Appliance lamp): a generic lamp for an appliance. Some, like a switch heater, attach to track; others, like a hotbox alarm, do not and carry a milepost. Set Value to its name. Indication is <Name>K, fixed. Its one pin (to be renamed TRACK; it is MC today by copy) is optional: wired to a track net, the appliance belongs to that circuit; wired to anything else is an import error; unwired, Milepost and CP Name place it.
  • Contact (Appliance contact): the lever counterpart of AUXILIARY, a generic input or sensor. Set Value to its name and Style to its consumer. Its one pin follows the AUXILIARY rule above.
  • MaintainerCall (Appliance lamp, Style maintainer_call): set Value to the control point's name; Name is <Value>MC. Wire MC to the House's MC pin.
  • OfficeUnit: place one. Set Value to the machine's name. Style is US&S. Wire Processor to the processor that runs the office logic.
  • PanelColumn: one per desk column. Set Value to the column number; the Column field follows. Set CP Name to the control point the column serves. Wire each plate of the column to one of its eight Column pins.

A plate is a device of the CTC machine in one column. Place one per lever or button on the desk. Set Value to the name of the field appliance it serves (783). Wire Column to the PanelColumn. Function pins are binary. An output pin is a lever contact; wire it to a driver input. An input pin is a lamp; wire it to a driver output. Control.<pin> names the control a contact sends; Indication.<pin> names the office indication a lamp shows. Both are fixed; an empty one is a deliberate none. A plate with lamps and contacts has two units: unit 1 contacts, unit 2 lamps. The units are not interchangeable.

  • PanelSwitch (Style switch): contacts NWS, RWS; lamps NWK, RWK. PanelSignal (Style signal): contacts NGS, HS, SGS; lamps NGK, SGK, TEK.
  • PanelLock (Style lock): contacts WLS, UNUSED; lamps WLQK, WLK. Indication.WLK is !<Value>WLK.
  • PanelMCall (Style maintainer_call): contact MCS; lamp MCK. Set Value to the control point's name; Name is <Value>MC.
  • PanelCode (Style code): contact CODE; Control.CODE is empty. PanelAuxiliary (Style non_vital): contact S; Control.S is <Value>S.

A model board lamp sits on the board, in no column, so it has no Column pin. Place one per lamp. Set Value to the lamp's name. Set Indication to the boolean expression of office indications that lights it. Color is fixed. Pin ~{LAMP} is a binary input; wire it to a driver output.

A transport is a mechanism: a broker, a serial port, a pulse line. Place one per line. Set Value to its name. Kind is fixed. Wire Processor to the processor that drives the line. Pin Transport is the net the encodings and nodes on this line attach to.

  • MQTT (Kind MQTT): set Broker. CMRInet (Kind CMRI): set Port and Baud. LocoNet (Kind LOCONET): set Port. TimeCode (Kind TIMECODE): no setting.

A code line encoding rides a transport and provides a code line. Place one per code line. Set Value to the code line's name. Wire Transport to the transport. Pin Codeline is the code line: wire every Interlocking and House on it to it.

  • AAR (Kind AAR): Topic is the MQTT topic root; <STRUCTURE:RAILROAD:Name> in it takes the Railroad symbol's Name.
  • Chart names the encoding chart for the item: its encoding map and serializer rules. US&S-506 (Kind USS506) and Bits (Kind BITS) both carry it; Bits also takes ControlBytes and IndicationBytes.

An I/O encoding states what rides a transport. It provides no net. Place one per transport that carries remote I/O. Set Value to its name. Wire Transport to the transport.

  • JMRI (Kind JMRI): Topic is the JMRI channel root. CMRInet (Kind CMRI): Version is the protocol version.

Place one per powered or sensed switch. Style lists the trackplan switch styles the device serves. Pin M is the binary demand: asserted means REVERSE; wire it to a driver output. ~{N} and ~{R} are the point contacts; wire them to driver inputs.

  • Device-Switch-OS adds unit 3, ~{OCC}: the OS circuit's occupancy; wire it to a driver input.
  • Device-Switch-ManualSensed (Style manual_sensed) has contacts only: ~{N}, ~{R}.
  • Device-Lock (Style lock, dual): UNLOCK is the demand; ~{LOCKED} the sense. Set settle_ms when the sense is not wired.

Place one per detected track circuit. Set Value to the circuit name. Pin ~{OCC} is the binary occupancy; wire it to a driver input.

  • Optical has hold_ms (default 1500): how long occupancy holds after the sensor clears.
  • Device-Lamp: set Value to the lamp's name. Pin ~{LAMP} is a binary input; wire it to a driver output. Set Address only on a pixel bus.
  • Device-Contact: set Value to the Contact appliance's name. Pin ~{IN} is a binary output; wire it to a driver input.

A local plate is a lever or key at the location, not in the CTC machine, so it has no Column pin. Set Value to the switch's name. Output pins are contacts; wire them to driver inputs. Input pins are lamps; wire them to driver outputs.

  • Local-Switch (Style switch): contacts NWS, RWS; lamps NWK, RWK. Local-Lock (Style lock): contact WLQ; lamps WLQK, WLK; Invert is WLK.

A whole-mast device hands the mast's indication to a driver that takes a whole mast, or to head devices of the older shape. Place one per mast of the trackplan-heads group. Set Value to the mast's name (836NAB). Pin IND is an indication output. Wire it to a Driver-JMRI-SignalMast IND, or to the IND of each head device of the older shape.

A head device of this shape makes its own lamps or arm. Place one per head of a mast of the trackplan-heads group. Set Value to the mast name plus the head letter (784A). The last letter of Name is the head letter. Style is fixed and must match the trackplan head's Style. Pin IND is the indication input; wire it to the whole-mast device's IND. Every other pin is a hardware input of one kind; wire each to a driver output.

  • CPL: binary ~{R}, ~{Y}, ~{G}. CPL-Encoded: binary S0, S1, the select code. CPL-Pixel: color ~{R}, ~{Y}, ~{G}, one pixel each.
  • CL-RGB: binary ~{R}, ~{G}, ~{B}. CL-Pixel: color RGB, one pixel; set Address to its index on the chain.
  • Semaphore-UQ, -LQ: position ARM; set stop_deg, approach_deg, clear_deg.
  • The Head field is tolerated, not required. The head letter is read from Name.

A field mast device binds a mast of the derived-indications group to its heads. Place one per such mast. Set Value to the trackplan mast's name (246AB). It has no Style, Kind or Indications: the pin set states the head count. Pins A, B, C are indication outputs, one per head position, top down. Wire each to one anonymous head's IND.

An anonymous head is one head of a given model at one position on a field mast. Place one per head position. It has no Name. The mast pin its IND is wired to identifies it: the mast's Name plus the letter A, B or C. Value shows Style and is never read. Style is the manufacturer model, fixed by the symbol. The symbol has no setting. Pin IND is the indication input; wire it to one pin of the field mast device. Pin APP is the indication output, the head word; wire it to the APP of one or more encoders.

An encoder turns a head word into hardware: lamps, a select code, pixels or a servo arm. Place one per head, or two when a semaphore has a lamp behind its blade. It has no Name and no Appliance. The head it serves identifies it. Value shows Kind and is never read. Kind is fixed and names the hardware. Pin APP is the one indication input; wire it to the head's APP. Every hardware-side pin is an input of kind binary or position; wire each to a driver output. CHAIN is an attachment to a pixel chain; wire it to a Driver-GPIO-Pixel D.

  • RYG (Kind RYG): binary ~{R}, ~{Y}, ~{G}. RGB (Kind RGB): binary ~{R}, ~{G}, ~{B}. 3MUX2A (Kind 3MUX2A): binary S0, S1, the select code.
  • Lamp (Kind LAMP): binary ~{LAMP}, lit for every head word except DARK.
  • Pixel-RYG (Kind PIXEL_RYG): CHAIN; set Address.R, Address.Y, Address.G to each lamp's pixel index. Pixel-RGB (Kind PIXEL_RGB): CHAIN; set Address to the pixel index.
  • Servo (Kind SERVO): position ARM; set stop_deg, approach_deg, clear_deg.

Place one per chip. Set Address to the chip's I2C address. The sixteen pins are in four units of four; the symbol fixes their kind.

  • MAX7311, MAX7313, MCP23017: binary, bidirectional pins; the device that lands on a pin sets its direction.
  • MAX7313-SPCoastcTc: one unit with each pin's direction fixed to the desk column's wiring. Wire the column's plates to it.
  • PCA9685-PWM (IC PCA9685): level outputs; set frequency_hz; wire lamps to it. PCA9685-Servo: position outputs; set min_us and max_us; wire ARM pins to it.

Place one per processor pin in use. Set Address to the board core's pin name. Pin D is the one function pin.

  • Digital: D is binary, bidirectional. Pixel: D is color, the chain; wire pixel encoders' CHAIN pins and older heads' pixel pins to it.

A node is a driver on a CMRInet line that provides the IOBus its bits sit on. A bit is one input or output of that node. Place one node per CMRInet node and one bit symbol per bit in use.

  • Node (Kind NODE): set Address to the UA, NodeType to C, M or N, InputBytes and OutputBytes. Wire pin Transport to the CMRInet transport; the importer reads that wire. Pin IOBus is the bus for its bits.
  • IB (Kind IB): D is a binary input to the node; wire a device output to it. OB (Kind OB): D is a binary output; wire a device input to it. Set Bit; set Node only when the sheet holds two nodes.

A JMRI driver is one JMRI object on an MQTT transport. Kind is the object class. Place one per object. Address is the JMRI object name. Leave it empty to name the object after the device the driver serves.

  • Turnout (Kind TURNOUT): M, binary output; wire a Device-Switch M to it. Turnout-Feedback: ~{N}, ~{R}, binary inputs; wire the switch's contacts to them.
  • Sensor (Kind SENSOR): S, binary output, the FieldUnit publishes; wire a detector's ~{OCC} to it. Sensor-Feedback: S, binary input, the FieldUnit reads.
  • Light (Kind LIGHT): ON, binary; INTENSITY, level. SignalMast (Kind SIGNALMAST): IND, indication input; wire a whole-mast device's IND to it.
  • Place one on a net to give every symbol on the net the same settings. Set Value to a short name. Add one field per setting, in lower_snake_case. Wire its one pin, net, to the net.
